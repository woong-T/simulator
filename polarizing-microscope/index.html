부분 명칭

박편 선택

관찰 순서

  1. 광원을 켜고 밝기를 조절한다

    하부 편광판(편광자)은 항상 광로에 들어 있다 — 보통 진동 방향은 동–서(E–W).

  2. 박편을 재물대에 올리고 클립으로 고정한다

    박편 두께는 표준 0.03 mm(30 µm). 커버글라스가 위로 오게 놓는다.

  3. 저배율(4×) 대물렌즈로 초점을 맞춘다

    조동나사로 대강 → 미동나사로 정밀하게. 배율을 올릴 땐 회전판만 돌린다.

  4. 개방 니콜(PPL)에서 관찰한다 — 검광판 제거

    광물 고유의 색, 다색성(재물대 회전 시 색 변화), 형태, 벽개, 굴절률 차이에 따른 돌출(relief)을 본다.

  5. 검광판을 밀어 넣어 직교 니콜(XPL)로 바꾼다

    두 편광판이 90°로 교차 → 시료가 없으면 시야가 완전히 검게 된다. 광물은 간섭색을 낸다.

  6. 재물대를 돌리며 소광을 관찰한다

    비등방성 광물은 360° 회전 동안 90°마다 4번 어두워진다(소광). 십자선과 벽개가 이루는 각 = 소광각.

  7. 석고판(λ판)을 끼워 색 변화를 본다

    530 nm가 더해지거나 빠지면서 회색 광물이 청색/황색으로 갈라진다 — 광학 방위 판정에 사용.

  8. 40×에서 베르트랑 렌즈로 간섭상을 본다

    콘오스코프 관찰: 검은 십자(아이소자이어)와 색 고리. 일축성/이축성, 광학적 부호(+/−) 판정.

간섭색 (미셸-레비 색표)

0 nm550 (1차 적)11001650 nm

간섭색은 복굴절 × 박편 두께(광로차)로 결정됩니다. 석고판을 넣으면 모든 광로차에 530 nm이 더해지거나 빠져 색이 이동합니다.

개방 니콜 vs 직교 니콜

개방 니콜 (PPL, 검광판 없음)

고유색·다색성·형태·벽개·돌출 관찰. 시야가 밝다.

직교 니콜 (XPL, 검광판 삽입)

간섭색·소광·쌍정 관찰. 편광자를 회전해 십자를 풀면 시야가 점점 밝아진다. 등방성 광물(석류석 등)과 유리는 항상 검게 보인다.
